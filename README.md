This is a **professional portfolio website** built with **HTML, CSS, and JavaScript** to present my:

- ✨ **Modern & Interactive UI** - Smooth animations and responsive design
- 🌙 **Dark/Light Theme Toggle** - Easy on the eyes in any lighting
- 📱 **Fully Responsive** - Works perfectly on mobile, tablet, and desktop

## 🔧 Customization

To personalize this portfolio:

1. **Update Personal Info:**
   - Edit `index.html` with your details
   - Update the files in `resume/`

2. **Change Colors:**
   - Modify CSS variables in `style.css` (`:root` section)

3. **Add New Projects:**
   - Add project cards in `index.html`
   - Add tech badges and links

4. **Update Images:**
   - Replace images in `images/` folder
   - Maintain same file names or update references
